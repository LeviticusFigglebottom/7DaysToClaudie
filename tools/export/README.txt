HOLLOWMERE  @VERSION@
=====================

An open-world survival-horror game. Every model, texture and sound in it was generated by the
project's own code.

Running it
----------
Windows: unzip anywhere and run Hollowmere.exe. Hollowmere.console.exe is the same game with a
console window that shows the log as it plays (useful if something goes wrong).
Linux:   unzip anywhere and run ./Hollowmere.x86_64

Keep Hollowmere.pck next to the program: it holds the whole game.

You need a GPU with Vulkan 1.2 or Direct3D 12 (most cards from 2016 on: GTX 900 / RX 400 and
newer). Older drivers make Godot fall back to OpenGL, where fog, weather and lighting are wrong.

Controls
--------
WASD move · Shift sprint · C/Ctrl crouch · Space jump · E interact (hold to search)
LMB use / attack / place · RMB block / consume · R rotate piece · V log pose · X cancel
G drop · F light · 1-6 toolbelt · Tab salvage roll (inventory, crafting) · B field manual
T tether · F5 / F9 quicksave / quickload · Esc pause

Saves, settings and logs
------------------------
Windows: %APPDATA%\hollowmere\   (logs\godot.log is the log of the last run)
Linux:   ~/.local/share/hollowmere/

If the game crashes, please send logs\godot.log (and the console window's text if you used
Hollowmere.console.exe).
