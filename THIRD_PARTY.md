# Third-party software and assets

Hollowmere ships **no downloaded or asset-store content**: every model, texture, material,
animation, sound and icon is generated by this repository's own code (`tools/assetgen/`,
Godot procedural meshes/shaders). The only third-party pieces are tools, an engine, a test
addon and open-licensed fonts, listed here with their licenses and how they are obtained.
Versions are pinned in `tools/versions.env` / `tools/requirements.txt`.

| Dependency | Version | License | Use | Obtained from / how |
|---|---|---|---|---|
| Godot Engine | 4.7.2-stable | MIT | Engine and editor (headless for CI) | downloads.godotengine.org, SHA-512 pinned (`make setup`) |
| Jolt Physics | bundled in Godot 4.7 | MIT | 3D physics backend | part of the Godot binary |
| Blender | 5.2.2 LTS | GPL-3.0-or-later | **Tool only**: headless procedural model/rig/animation generation. Outputs are our own work (the GPL does not extend to program output) | download.blender.org, SHA-256 verified (`make setup`) |
| GUT (Godot Unit Test) | 9.7.1 | MIT | Unit/integration tests (`game/addons/gut`, vendored) | jsDelivr mirror of github.com/bitwes/Gut (`make vendor-gut`). **Local patch**: `gut_plugin.gd` skips its online update check when running headless (no network calls from imports/CI) |
| NumPy | 2.4.6 | BSD-3-Clause | Texture/audio synthesis | PyPI into `.tools/venv` |
| SciPy | 1.17.1 | BSD-3-Clause | Audio DSP filters | PyPI into `.tools/venv` |
| Pillow | 12.3.0 | MIT-CMU (HPND) | PNG I/O | PyPI into `.tools/venv` |
| IBM Plex Mono (Regular, Bold) | 2.x | SIL OFL 1.1 | UI font (HUD, tether, menus) | `game/assets/fonts/`, license file alongside, SHA256SUMS pinned |
| EB Garamond (variable) | — | SIL OFL 1.1 | Printed documents (field manual headings) | `game/assets/fonts/` + OFL text |

CI/test-only system packages (not shipped): Xvfb, Mesa (lavapipe software Vulkan) for headless
screenshots and previews; standard Ubuntu packages installed by `.github/workflows/ci.yml`.

## Policy
* Adding a dependency requires an ADR if it affects the build or runtime, an entry here (name,
  version, license, purpose, source, checksum), and a pinned version in `tools/`.
* No generated or downloaded binary assets are committed: `game/assets/generated/` is rebuilt by
  `make assets` (ADR-0002). Fonts are the only committed binary third-party files.
