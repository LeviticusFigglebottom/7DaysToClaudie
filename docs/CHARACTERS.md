# Characters — rig, animation and dismemberment contract

Generated by `tools/assetgen/blender/generators/character_*.py`. Consumed by
`game/src/ai/enemy/` (zombie bodies) and `game/src/player/viewmodel` (first-person arms).

## Hollowed bodies (`models/characters/<id>.glb`)
Ids: `hollow_a`, `hollow_b`, `hollow_c`, `hollow_d` (walkers: varied build/height/clothing),
`lurcher_a`, `lurcher_b` (gaunt, long-limbed, torn clothing), `keener_a` (swollen throat sac,
elongated jaw). All share **one skeleton layout** so every animation works on every body.

* Height ≈ 1.55–1.90 m (params). T-pose or A-pose rest, facing −Y, feet at Z = 0, origin between feet.
* Armature object named `Armature`. Bone names (exactly):
  `root, hips, spine, chest, neck, head, jaw,
   shoulder.L, upper_arm.L, forearm.L, hand.L, shoulder.R, upper_arm.R, forearm.R, hand.R,
   thigh.L, shin.L, foot.L, toe.L, thigh.R, shin.R, foot.R, toe.R`
* **Segmented skinned meshes** (all children of `Armature`, all skinned to it), one object per
  dismemberable region, named exactly:
  `body_head, body_torso, body_upper_arm.L, body_forearm.L, body_upper_arm.R, body_forearm.R,
   body_thigh.L, body_shin.L, body_thigh.R, body_shin.R` (hands/feet belong to forearm/shin).
  Segments overlap ~1 cm at joints so there are no cracks. The game hides a segment chain and
  attaches a stump cap when a limb is severed.
* **Stump caps**: `stump_neck, stump_shoulder.L/R, stump_elbow.L/R, stump_hip.L/R, stump_knee.L/R`
  — small gore caps (material `M_gore`), rigidly weighted to the parent bone, hidden by default
  (the game shows them on dismemberment).
* **Gibs** (separate file `models/characters/gibs.glb`): unskinned meshes `gib_head`,
  `gib_arm_upper`, `gib_arm_lower`, `gib_leg_upper`, `gib_leg_lower`, `gib_chunk_a..d`,
  origin at the cut end; materials `M_skin_hollow` + `M_gore`.
* Materials: `M_skin_hollow` (pale/grey mottled, Bloom veins), clothing `M_cloth_denim`,
  `M_cloth_flannel`, `M_cloth_tshirt`, `M_cloth_jacket`, `M_cloth_hospital`, `M_leather_boot`,
  `M_hair`, `M_teeth`, `M_eyes_hollow` (milky), `M_bloom_growth` (fungal growth), `M_gore`.
  Vertex colour R = AO, G = dirt/blood mask, B = Bloom growth mask.
* Budget ≤ 16k triangles per body (`char_build.BODY_BUDGET`); the head gets ~4.2k so the face
  holds its shape at arm's length. Godot's import LODs reduce distant bodies.

## First-person arms (`models/characters/fp_arms.glb`)
* Separate armature `Armature` with bones `root, upper_arm.L/R, forearm.L/R, hand.L/R` and finger
  bones `thumb_1/2.L/R, index_1/2.L/R, fingers_1/2.L/R` (middle+ring+pinky merged per hand).
* Camera at origin looking −Y in Blender (Godot −Z after conversion? see note): arms enter from the
  lower edge of view. Sleeves `M_cloth_jumpsuit` (Remand Program orange-grey jumpsuit), skin
  `M_skin_human`, wrist **tether** device on the left wrist (`M_tether`, screen `M_tether_screen`).
* Socket empties: `socket_hand.R` (tool grip point: tools parent here), `socket_hand.L`.
* Actions: `fp_idle`, `fp_walk_bob` (loop), `fp_idle_grip`, `fp_walk_grip` (the same with the right
  hand closed round a held tool; the viewmodel picks them while an item is held), `fp_swing` (overhead chop), `fp_swing_side`,
  `fp_stab`, `fp_throw`, `fp_raise_wrist` (look at tether, hold), `fp_lower_wrist`, `fp_use`
  (eat/drink to mouth), `fp_carry_log` (log on right shoulder), `fp_place`, `fp_light` (lighter flick),
  `fp_block`.
* Note on axes: author FP arms facing −Y like everything else; the game rotates the viewmodel root.
